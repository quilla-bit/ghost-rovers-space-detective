# Ghost Rovers: Voices from the Cosmos

**2026 NASA Space Apps Challenge:** *Abandoned but not Forgotten: Storytelling about NASA's Discarded Equipment on the Moon and Mars*

## Project Overview
*Ghost Rovers: Voices from the Cosmos* is an interactive digital space museum designed for school-age explorers (ages 8–14). Visitors toggle across **The Moon**, **Mars**, and **Deep Space** to tune into first-person audio transmissions from six iconic NASA spacecraft, explore "By the Numbers" Space Math metrics, and unlock Explorer Badges through the Junior Space Detective quiz.

## Featured NASA Spacecraft
1. **Apollo 11 Laser Ranging Retroreflector** (Moon — Sea of Tranquility)
2. **Surveyor 3** (Moon — Ocean of Storms)
3. **Opportunity Rover** (Mars — Meridiani Planum)
4. **InSight Lander** (Mars — Elysium Planitia)
5. **Ingenuity Mars Helicopter** (Mars — Jezero Crater)
6. **Voyager 1** (Deep Space — Interstellar Space)

## Tech Stack
- **Frontend:** React + Vite
- **Styling:** Custom responsive dark-mode CSS3
- **Data:** Static JSON (`src/data/artifacts.json`) & HTML5 Audio (`public/audio/`)
